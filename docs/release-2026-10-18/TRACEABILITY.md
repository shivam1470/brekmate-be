# BrekMate coordinated feature traceability — 18 October 2026

Scope: single pure-vegetarian outlet, native-only customer ordering, staff browser workspace, cash delivery/pickup. Future outlet support is an architectural direction: `outletId` is currently fixed to `main` in production config. This is not a verified multi-outlet service. “Verified” below means local tests for the stated behavior, not live AWS/device acceptance. Source paths are relative to the four sibling repositories.
